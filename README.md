# MU AI 日內交易策略 — SoAI 2026

## 策略概述

本策略專為 **美光科技 (MU)** 設計，採用 **三層決策架構**，通過規避新聞及基本面噪音，利用純價格行為 (Price Action) 及指數情緒共振進行交易。

| 項目 | 值 |
|------|-----|
| 交易標的 | MU (Micron Technology) |
| 運行週期 | 3–5 分鐘 K 線（日線回測模式亦支援） |
| 初始資金 | $1,000,000 USD |
| 手續費 | 雙邊各 2 bps (0.02%) |
| 持倉時間 | 純日內，美東 15:55 強制清倉 |

## 三層決策架構（v2.3 — RS 相對強弱 + Daily VWAP 錨點 + VWAP 回踩進場）

### 大趨勢錨點：Daily VWAP（v2.2）
- Daily VWAP 每天開盤重置，從當日第一根 bar 起累計 Σ(典型價×量)/Σ(量)
- **僅當 MU 價格 > Daily VWAP（今日多頭控盤）時，5 分鐘買點才有效**
- 價格 < Daily VWAP = 今日主力出貨 → 5 分鐘買點一律作廢
- 不受隔夜跳空影響，反映「今天機構資金的總體態度」
- （v2.1 曾用 1H EMA20，v2.2 改為 Daily VWAP）

### 第 1 層：母系統 — 個股相對強弱 (RS Ratio)
- `RS_Ratio = MU Price / SMH Price`
- **只要 RS_Ratio > 10 週期 EMA → MU 比半導體板塊強，允許做多**
- 摒棄「SMH > SMH VWAP」式硬性開關：即使大盤/SMH 盤整，只要 MU 相對更強即可入場
- 對標基準亦已解綁 SPY，改用 SMH（大盤對半導體板塊不敏感）

### 第 2 層：核心系統 — 價格突破 VWAP
- MU 價格必須位於 5 分鐘 VWAP 之上（價格向上突破）

### 第 3 層：子系統 — VWAP 回踩進場（v2.3 核心改動）
- 取代「突破當下直接追高」：僅在價格回踩 5m VWAP 後重新站上時進場
- 回踩確認（任一）：當根 low 觸及 VWAP 附近（≤VWAP×1.002）／ 前一根收盤在 VWAP 之下
- **RSI(14) > 52**（v2.3 由 40 提高，過濾高位追入）
- **放量倍數 ≥ 1.9×**（v2.3 由 1.5 提高，過濾假突破）
- 止盈：布林帶上軌 / RSI > 70 → 平倉 50%；跌破 20-EMA → 全數清倉

## 強制清倉（v2.1 bug 修復）

- **15:50 後禁止開新倉**：Lumibot 在美東 15:55 後不再迭代，15:55 買入將無法當日清倉 → 直接禁止
- **15:55 強制清倉**：無論持倉標記如何，一律清倉；`_position_quantity` 追蹤值兜底，避免訂單結算延遲時漏清
- 已驗證：60 天回測 **0 筆隔夜持倉**

## 風控約束

| 約束 | 值 |
|------|-----|
| 倉位模型 | 固定風險 + ATR 自適應 |
| 單筆最大風險 | 總資金 2%（$20,000） |
| 止損距離 | 1.5 × ATR |
| 單筆頭寸上限 | $500,000（總資金 50%，v2.4 由 250K 提高）|
| 日內熔斷 | 虧損 $15,000（1.5%）→ 立即停機 |
| 交易頻率限制 | 單日最多 20 筆 |
| 開盤保護 | 9:30–10:00 僅監控不下單 |

## 資金效率（v2.4）

- **底倉階段允許再開新倉**：鎖利 50% 進入底倉（stage=2）後，不再直接 return，允許當日再開第二、第三個波段；全倉（stage=1）時仍禁止疊加
- **倉位上調至 50%**：單筆建倉上限 $250K → $500K，資金使用率翻倍
- 14 個月長歷史驗證：Sharpe 0.08 → **0.60**，日內淨損益 +$48K → **+$63K**

## ADX 網格策略（v2.5，可選）

`STRATEGY=grid python backtest.py` 可切換到 ADX 網格策略（`strategies/grid_strategy.py`）：

- **ADX(14) < 25** → 無趨勢震盪市 → 允許啟動網格（基準價下方分層低買，回升一格賣出）
- **ADX(14) ≥ 25** → 單邊趨勢形成 → 熔斷，暫停新建網格層（已持倉層仍可賣出）
- 網格參數：3 層、間距 1×ATR、每層 $50K、基準=當日開盤價
- 14 個月結果：+$2,922（勝率 62%，盈虧比 1.14，0 隔夜）

**對比結論**：MU 是強趨勢股（ADX<25 僅佔 44% 時間），網格環境有限；
VWAP 回踩策略（+$63K）遠優於網格策略。建議以 VWAP 策略為主策略。

## ADX 混合模式（v2.6，可選）

`STRATEGY=hybrid python backtest.py` 切換到混合策略（`strategies/hybrid_strategy.py`）：

- **ADX < 22** → 網格引擎（震盪市低買高賣）
- **ADX ≥ 28** → VWAP 回踩引擎（趨勢市順勢跟單）
- **22 ≤ ADX < 28** → 維持現狀（遲滯帶，避免 25 門檻附近抖動）
- 切換瞬間強制清倉再進入新模式
- 14 個月結果：**+$49,412**（勝率 58.7%，盈虧比 1.98，0 隔夜，97 次切換）

**三策略終極對比（14 個月）**：

| 策略 | 日內淨損益 | 勝率 | 盈虧比 | Sharpe |
|------|-----------|------|--------|--------|
| 純網格 | +$2,922 | 62% | 1.14 | -3.68 |
| **純 VWAP 回踩** | **+$63,118** | 69% | 2.82 | **0.60** |
| ADX 混合 | +$49,412 | 59% | 1.98 | 0.17 |

**結論**：MU 上 VWAP 回踩引擎在所有市場狀態（含震盪）均優於網格，
ADX 判別器正確運作但未帶來增量價值（切換摩擦抵消）。
**最終建議：以純 VWAP 回踩策略（v2.4）參賽。**

## 倉位模型改善 + 槓桿支援（v2.8）

- **倉位基準改為總組合價值（equity）**：倉位計算以 equity × 2% 固定風險，
  取代舊的 cash 基準 — 大幅提升資金使用率
- **單筆上限 = 初始資金 × LEVERAGE**（1x = $1M，2x = $2M）
- 現金硬上限：倉位市值 ≤ 現金 × LEVERAGE（避免透支）

**14 個月回測對比（純 MU，修復每日盈虧基準後）**：

| 槓桿 | 買入 | 平均槓桿 | 勝率 | 盈虧比 | 日內淨損益 | Sharpe | 回撤 |
|------|------|---------|------|--------|-----------|--------|------|
| 1x | 50 | 0.95x | 69.0% | 2.82 | +$121,589 | 1.28 | -1.4% |
| **1.2x（預設）** | 50 | 1.14x | 69.4% | 2.82 | **+$146,011** | **1.41** | -1.7% |
| 2x | 8 | 1.99x | 30% | 0.14 | -$17,210 | -5.81 | -1.7% |

**結論**：
- 修復 `_day_start_value` 每日重置 bug（原為累積盈虧 → 累虧超 $15K 後策略永久停機）
- **1.2x 溫和槓桿最優**（+$146K，Sharpe 1.41）：槓桿體現在「總曝險 =
  equity×1.2 − 既有持倉」，而非單筆放大 → 資金不被單筆吃光
- **2x 災難**：單筆頂到 $2M 全倉 → 資金一次用盡 → 訊號中斷
- 最終建議：**LEVERAGE = 1.2**

## SPY 測試（v2.8.3，同策略套用大盤 ETF）

將 `TRADE_SYMBOLS` 切為 `["SPY"]`（RS 參照維持 SMH），14 個月結果：

| 指標 | SPY | MU（對照）|
|------|-----|----------|
| 日內淨損益 | +$6,277 | +$146,011 |
| 勝率 | 61.4% | 69.4% |
| 盈虧比 | 1.43 | 2.82 |
| 買入筆數 | 27 | 50 |

**結論**：策略 edge 與標的波動/趨勢性高度相關 — MU 是高波動動能股
（5 分鐘 ATR $0.3+），VWAP 回踩訊號質量高；SPY 波動低、訊號少且弱
（RS=SPY/SMH 在半導體強勢時會過濾掉多數訊號）。**建議維持 MU 為主標的**；
SPY 需重新調參（RS 參照換 QQQ、降低進場門檻）才可能有正 edge。

## SNDK 測試（v2.8.4，同策略套用 SanDisk）

SanDisk（SNDK，2025 年由 WD 分拆的閃存公司，與 MU 同屬存儲半導體），
14 個月結果（RS 參照 SMH）：

| 指標 | **SNDK** | MU | SPY |
|------|---------|-----|-----|
| 日內淨損益 | **+$178,717** | +$146,011 | +$6,277 |
| 勝率 | 56.6% | **69.4%** | 61.4% |
| 盈虧比 | 1.55 | **2.82** | 1.43 |
| 買入筆數 | 109 | 50 | 27 |
| Sharpe | 1.19 | **1.41** | -4.13 |
| MaxDD | -5.4% | **-1.7%** | -0.5% |

**結論**：SNDK 總收益最高（+$179K，交易頻率高 2 倍），但 Sharpe 較低、
回撤大 3 倍（-5.4%）、勝率較低 — 靠少數大贏家（5/1 +$42K、6/11 +$39K、
10/29 +$35K）拉動，月收益不均（單月最差 -$18K）。
**MU 仍是風險調整後最優（Sharpe 1.41）**；若追求最大 Terminal Return
且能承受回撤，SNDK 是備選。官方比賽僅 8/16–9/15 一個月，MU 的穩健性
更適合短期賽制。

## 快速回測

```bash
# 分鐘級回測（Pandas CSV 模式，建議先下載數據）
python download_minute_data.py    # yfinance 抓最近 7 天 1 分鐘 OHLCV
python backtest.py                # 5 分鐘 K 線回測

# 日線回測（Yahoo Finance，免 API Key）
python backtest_yahoo.py
```

**模式切換**：在 `strategies/params.py` 修改 `SLEEPTIME`（`"5M"` / `"1M"` / `"1D"`）與 `RESAMPLE_MINUTES`（分鐘級 K 線重取樣週期）。分鐘級回測時交易時段（9:30–10:00 監控期、15:55 強制清倉）自動以美東時間生效。
